## ⚡ Introduction

**No device tree uploading needed.**  
Simply paste your Recovery Tree Git URL and get a fully built custom recovery in record time — completely private with instant Telegram notifications.

---

## ✨ Key Features

- ⚡ **Blazing Fast Builds** on powerful AWS EC2 high-spec servers
- 🔒 **Fully Private** — Only you can access your builds
- 📲 **Instant Telegram Notifications**
- 🔗 **URL Based** — Support any public Recovery or Device Tree
- 🌍 **Universal Support** — TWRP, OrangeFox, PitchBlack, SHRP, OmniROM & any custom fork
- 🛡️ Advanced CCache, optimizations, and multi-version support (Android 10-16)

---

## 🚀 How to Use

1. Navigate to the **Actions** tab
2. Select **"Custom Recovery Builder"** workflow
3. Click **"Run workflow"**
4. Enter the details:

| Parameter               | Description                                | Example |
|-------------------------|--------------------------------------------|---------|
| Device Codename         | Device codename                            | `whyred` |
| Recovery Type           | Type of recovery                           | `twrp` |
| Android Version         | Target Android version                     | `14` |
| Recovery Tree URL       | Full Git URL of the tree                   | `https://github.com/TeamWin/android_device_xiaomi_whyred` |
| Manifest Branch         | Branch name (optional)                     | `twrp-14.1` |
| Telegram Chat ID        | Your Telegram Chat ID                      | `123456789` |
